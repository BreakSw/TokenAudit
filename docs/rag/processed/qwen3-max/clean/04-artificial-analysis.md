Comparison Summary
Qwen3 Max is above average in intelligence and reasonably priced when comparing to other non-reasoning models of similar price. The model supports text input, outputs text, and has a 262k tokens context window.
Qwen3 Max scores 24 on the Artificial Analysis Intelligence Index, placing it above average among comparable models (median: 23).
Pricing for Qwen3 Max is $1.20 per 1M input tokens (moderately priced, median: $2.00) and $6.00 per 1M output tokens (moderately priced, median: $10.00).
At 59 tokens per second, Qwen3 Max is slower than average (68).

Common questions about Qwen3 Max
When was Qwen3 Max released?

Who created Qwen3 Max?

How intelligent is Qwen3 Max?

How fast is Qwen3 Max?
Qwen3 Max generates output at 59.2 tokens per second (based on Alibaba's API), which is below average compared to other non-reasoning models in a similar price tier (median: 67.9 t/s).
What is the latency of Qwen3 Max?
Qwen3 Max has a time to first token (TTFT) of 2.35s (based on Alibaba's API), which is somewhat higher than average compared to other non-reasoning models in a similar price tier (median: 1.47s).
How much does Qwen3 Max cost?
Qwen3 Max costs $1.20 per 1M input tokens (better than average, median: $2.00) and $6.00 per 1M output tokens (better than average, median: $10.00), based on Alibaba's API.
What is Qwen3 Max API pricing?
Qwen3 Max costs $1.20 per 1M input tokens and $6.00 per 1M output tokens (based on Alibaba's API). For a blended rate (7:2:1 cache hit/input/output ratio), this is $1.68 per 1M tokens. Pricing may vary by provider. Compare provider pricing
Is Qwen3 Max a reasoning model?

What input modalities does Qwen3 Max support?

What output modalities does Qwen3 Max support?

Can Qwen3 Max process images?

Is Qwen3 Max multimodal?
No, Qwen3 Max is not multimodal. It only supports text input.
