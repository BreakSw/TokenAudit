**Claude** is a series of [large language models](https://en.wikipedia.org/wiki/Large_language_model "Large language model") developed by American software company [Anthropic](https://en.wikipedia.org/wiki/Anthropic "Anthropic"). Claude was released as an [AI](https://en.wikipedia.org/wiki/Generative_AI "Generative AI")-based [chatbot](https://en.wikipedia.org/wiki/Chatbot "Chatbot") in March 2023. It is also used in [AI-assisted software development](https://en.wikipedia.org/wiki/AI-assisted_software_development "AI-assisted software development").

Claude is trained using a [constitution](https://en.wikipedia.org/wiki/AI_alignment#Model_specifications "AI alignment"), a technique developed by Anthropic to improve ethical and legal compliance. Since Claude 3, each generation has typically been released in three sizes, named Haiku (the least capable), Sonnet, and Opus (the most capable). In 2026, an additional model named [Claude Mythos](https://en.wikipedia.org/wiki/Claude_Mythos "Claude Mythos") was released to a handful of companies and organizations; this was followed by the release of [Claude Fable](https://en.wikipedia.org/wiki/Claude_Fable "Claude Fable"), a version of Mythos with stricter safeguards, to the general public.

[US federal agencies started phasing out the use of Claude](https://en.wikipedia.org/wiki/Anthropic%E2%80%93United_States_Department_of_Defense_dispute "Anthropic–United States Department of Defense dispute") after Anthropic refused to remove contractual prohibitions on the use of Claude for [mass domestic surveillance](https://en.wikipedia.org/wiki/Mass_surveillance_in_the_United_States "Mass surveillance in the United States") and [fully-autonomous weapons](https://en.wikipedia.org/wiki/Military_robot "Military robot").[\[1\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-BBC-2026-1)[\[2\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-2) Following the refusal, the [Department of Defense](https://en.wikipedia.org/wiki/United_States_Department_of_Defense "United States Department of Defense") (DoD) designated the company a "supply chain risk" and barred all U.S. private military contractors, suppliers, and partners from doing business with the firm. On March 26, 2026, a federal judge issued a [temporary injunction](https://en.wikipedia.org/wiki/Injunction "Injunction") against the DoD's designation.[\[3\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-DODInjunction-3)

## Products

### Claude

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=2 "Edit section: Claude")\]

Claude is an [AI](https://en.wikipedia.org/wiki/Generative_AI "Generative AI") chatbot.[\[4\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-4) It sometimes uses artifacts, introduced in June 2024, to generate and interact with code snippets and documents.[\[5\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-5)[\[6\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-6) In 2025, Anthropic added a web search feature to Claude.[\[7\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-7)[\[8\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-8)

Claude Pro and Claude Max are subscription services for additional access to Claude models. Max provides higher usage limits at an additional cost.[\[9\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-9) Grouped subscriptions include Claude Team and Claude Enterprise.[\[10\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-10) Claude experienced significant growth in the business market, with software subscriptions growing 4.9% month over month in February 2026.[\[11\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-11)

#### Chat sharing

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=3 "Edit section: Chat sharing")\]

A Claude feature allows users to share chats with anyone who has the link.[\[12\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-:2-12)

In July 2026, it was reported that some Claude conversations could be found through [Google Search](https://en.wikipedia.org/wiki/Google_Search "Google Search").[\[12\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-:2-12) The chats affected were those for which links were posted on the public internet. Technical analysis also suggests that a [robots.txt](https://en.wikipedia.org/wiki/Robots.txt "Robots.txt") rule on the Claude website prevented [web crawlers](https://en.wikipedia.org/wiki/Web_crawler "Web crawler") from accessing the content of shared chats, but this rule also made web crawlers unable to see the [noindex](https://en.wikipedia.org/wiki/Noindex "Noindex") directive intended to prevent web searchability.[\[13\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-13) Hundreds of shared Claude chats were already found to be searchable back in September 2025, following similar issues with the sharing features of OpenAI's [ChatGPT](https://en.wikipedia.org/wiki/ChatGPT "ChatGPT") and xAI's [Grok](https://en.wikipedia.org/wiki/Grok_(chatbot) "Grok (chatbot)").[\[14\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-14)

### Application programming interface

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=4 "Edit section: Application programming interface")\]

Claude is also provided through a [application programming interface](https://en.wikipedia.org/wiki/Application_programming_interface "Application programming interface") (API). In October 2024, the "computer use" feature was introduced by which an application can call the Claude API to attempt to give navigational control of the application via Claude's interpretation of screen content and simulation of keyboard and mouse input.[\[15\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Shakir-2024-15)

### Claude Code

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=5 "Edit section: Claude Code")\]

Claude Code, released in February 2025, is an [agentic](https://en.wikipedia.org/wiki/Autonomous_agent "Autonomous agent") [command line](https://en.wikipedia.org/wiki/Command_line "Command line") tool to delegate coding tasks from the terminal using natural language prompts.[\[16\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-cc1-16)[\[17\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-17) It was made generally available in May 2025 alongside Claude 4.[\[16\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-cc1-16)[\[18\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-18) Based on enterprise adoption, Anthropic reported a 5.5x increase in Claude Code revenue by July.[\[19\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-claude-code-enterprise-19)

On October 20, 2025, Anthropic launched a web version of Claude Code and a [sandboxing](https://en.wikipedia.org/wiki/Sandbox_(computer_security) "Sandbox (computer security)") feature.[\[20\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-20)

Coinciding with performance improvements tied to Claude Opus 4.5, Claude Code [went viral](https://en.wikipedia.org/wiki/Went_viral "Went viral") during the 2025–2026 winter holidays when people had time to experiment with it, including many non-programmers who used it for [vibe coding](https://en.wikipedia.org/wiki/Vibe_coding "Vibe coding").[\[21\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-21)[\[22\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-22)[\[23\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Morrone-2026-23)

In August 2025, Anthropic released Claude for Chrome, a [Google Chrome](https://en.wikipedia.org/wiki/Google_Chrome "Google Chrome") [extension](https://en.wikipedia.org/wiki/Browser_extension "Browser extension") allowing Claude Code to directly control the browser.[\[24\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-24) Also in August 2025, Anthropic revealed that a threat actor called "GTG-2002" used Claude Code to attack at least 17 organizations.[\[25\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-25) In November 2025, Anthropic announced that it had discovered in September that the same threat actor had used Claude Code to automate 80–90% of its espionage cyberattacks against 30 organizations.[\[26\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Tidy-2025-26)[\[27\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-27) All accounts related to the attacks were banned, and Anthropic notified law enforcement and those affected.[\[26\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Tidy-2025-26)

Claude Code is used by Microsoft,[\[28\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-28) Google,[\[29\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-29) and OpenAI employees. In August 2025, Anthropic revoked OpenAI's access to Claude, calling it "a direct violation of our terms of service".[\[30\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-30) In February 2026, Anthropic introduced Claude Code Security, which reviews codebases to identify [vulnerabilities](https://en.wikipedia.org/wiki/Vulnerability_(computer_security) "Vulnerability (computer security)").[\[31\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-31) In March 2026, the source code for the Claude Code [command-line interface](https://en.wikipedia.org/wiki/Command-line_interface "Command-line interface") application was leaked, revealing multiple upcoming features and models.[\[32\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-32)[\[33\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-33)

In May 2026, Anthropic introduced "Dreaming", a research preview feature for its Managed Agents API that consolidates an agent's persistent memory between sessions by merging duplicates and removing stale entries;[\[34\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-34)[\[35\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-35) a memory consolidation feature called autoDream had been identified in the March source code leak.[\[36\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-36)

### Claude Cowork

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=6 "Edit section: Claude Cowork")\]

Claude Cowork is a tool similar to Claude Code but with a [graphical user interface](https://en.wikipedia.org/wiki/Graphical_user_interface "Graphical user interface"), aimed at non-technical users. It was released in January 2026 as a "research preview".[\[37\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-wired-cowork-37)[\[38\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-mashable-cowork-38) Cowork is available as a desktop application for Mac and Windows and through a web interface.[\[39\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-tds-cowork-39) It provides Claude with access to a sandboxed shell and to user-selected folders on the local file system, allowing the model to read, write and edit files, execute code, and chain multi-step tasks within a single conversation, such as organising files on a user's computer or generating documents from material in a local folder.[\[40\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-duke-cowork-40)[\[41\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-wsj-cowork-41) A Wall Street Journal reporter who tested the tool noted user concerns about granting an AI agent broad access to a personal computer.[\[41\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-wsj-cowork-41) An early user reported that, after asking Cowork to organise the files on the desktop of his wife's computer, it deleted all the family photos requiring the restoration of the images from an [iCloud](https://en.wikipedia.org/wiki/ICloud "ICloud") backup.[\[42\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-42)[\[43\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-43)

In February 2026, Anthropic announced a wider enterprise release of Cowork, adding connectors for services such as [Google Drive](https://en.wikipedia.org/wiki/Google_Drive "Google Drive"), [Gmail](https://en.wikipedia.org/wiki/Gmail "Gmail"), [Docusign](https://en.wikipedia.org/wiki/Docusign "Docusign") and [FactSet](https://en.wikipedia.org/wiki/FactSet "FactSet"), and customisable plugins for domains including financial analysis, engineering and human resources; the company described the update as a transition into an "enterprise-grade product".[\[44\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-cnbc-cowork-44) In March 2026, Anthropic added Dispatch, an [AI agent](https://en.wikipedia.org/wiki/AI_agent "AI agent") feature that allows users to send prompts from a phone, with Claude being able to access programs on the user's computer, such as web browsers or spreadsheet applications, to carry out tasks.[\[45\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-45) According to developers, Cowork was mostly built by Claude Code.[\[38\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-mashable-cowork-38)

### Claude Design

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=7 "Edit section: Claude Design")\]

Claude Design is a collaborative visual creation tool released by Anthropic Labs on April 17, 2026, that lets users generate designs, prototypes, slides, and marketing materials through natural-language prompts. It is powered by Claude Opus 4.7 and can pull brand systems from a user's codebase or design files. Users can iterate on outputs through inline comments, direct edits, and adjustment sliders, and export results to [Canva](https://en.wikipedia.org/wiki/Canva "Canva"), [PDF](https://en.wikipedia.org/wiki/PDF "PDF"), [PPTX](https://en.wikipedia.org/wiki/Microsoft_PowerPoint "Microsoft PowerPoint"), [HTML](https://en.wikipedia.org/wiki/HTML "HTML"), or folders, with a handoff path to Claude Code for development. Claude Design launched as a research preview included with Claude Pro, Max, Team, and Enterprise subscriptions.[\[46\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-46)

### Claude Science

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=8 "Edit section: Claude Science")\]

Announced at the end of June 2026, Claude Science is a model designed to support scientists, with an emphasis on [cellular](https://en.wikipedia.org/wiki/Cell_biology "Cell biology") and [molecular biology](https://en.wikipedia.org/wiki/Molecular_biology "Molecular biology") and [drug development](https://en.wikipedia.org/wiki/Drug_development "Drug development").[\[47\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-:0-47)

## Training

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=9 "Edit section: Training")\]

See also: [Anthropic §Legal issues](https://en.wikipedia.org/wiki/Anthropic#Legal_issues "Anthropic")

Not to be confused with [Clawdbot](https://en.wikipedia.org/wiki/Clawdbot "Clawdbot").

Claude models are [generative pre-trained transformers](https://en.wikipedia.org/wiki/Generative_pre-trained_transformer "Generative pre-trained transformer") that have been trained to predict the next word in large amounts of text. Then, they have been [fine-tuned](https://en.wikipedia.org/wiki/Fine-tuning_(deep_learning) "Fine-tuning (deep learning)") using [reinforcement learning from human feedback](https://en.wikipedia.org/wiki/Reinforcement_learning_from_human_feedback "Reinforcement learning from human feedback") (RLHF) and constitutional AI in an attempt to enforce ethical guidelines.[\[48\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Time-2023-48)[\[49\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-49) **ClaudeBot** searches the web for content. It was criticized by [iFixit](https://en.wikipedia.org/wiki/IFixit "IFixit") in 2024 for accessing their site over a million times a day to scrape content without permission, and also for the resulting excessive load on their system.[\[50\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-50)[\[51\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-51)

### Constitutional AI

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=10 "Edit section: Constitutional AI")\]

[Anthropic](https://en.wikipedia.org/wiki/Anthropic "Anthropic") introduced an approach to [AI alignment](https://en.wikipedia.org/wiki/AI_alignment "AI alignment") called "Constitutional AI". The constitution is a document used to train Claude to be harmless and helpful without relying on extensive or expensive human feedback.[\[52\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Edwards-2023-52) _Time_ described this constitution as "somewhere between a moral philosophy thesis and a company culture blog post".[\[53\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Ostrovsky-2026-53)

The original version was a list of principles.[\[53\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Ostrovsky-2026-53) The first constitution for Claude was published in 2022. The 2023 update listed 75 guidelines for Claude to follow.[\[48\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Time-2023-48)[\[54\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Field-2026-54) The first constitutions included concepts taken from the 1948 [UN Universal Declaration of Human Rights](https://en.wikipedia.org/wiki/UN_Universal_Declaration_of_Human_Rights "UN Universal Declaration of Human Rights").[\[53\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Ostrovsky-2026-53)[\[52\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Edwards-2023-52) The 2026 version includes more thorough explanations for how Claude is intended to behave and why, and has 23,000 words, an increase from 2,700 in 2023.[\[55\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-55)

Claude is reportedly named after [Claude Shannon](https://en.wikipedia.org/wiki/Claude_Shannon "Claude Shannon"), a 20th-century mathematician who laid the foundation for [information theory](https://en.wikipedia.org/wiki/Information_theory "Information theory").[\[64\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Roose-2023-65)

### Claude

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=12 "Edit section: Claude")\]

The first version of Claude was released in March 2023.[\[58\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Roth-2023-58) It was available only to selected users approved by Anthropic.[\[65\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Matthews-2023-66)

### Claude 2

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=13 "Edit section: Claude 2")\]

Claude 2, released in July 2023, became the first Anthropic model available to the general public.[\[65\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Matthews-2023-66)

#### Claude 2.1

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=14 "Edit section: Claude 2.1")\]

Claude 2.1 doubled the number of tokens that the chatbot could handle, increasing its context window to 200,000 tokens, which equals around 500 pages of written material.[\[60\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Davis-2023-60) With the release of Claude 2.1, Anthropic also introduced the then-beta feature of tool use.[\[66\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-:1-67) The 2.1 model also produced [hallucinations](https://en.wikipedia.org/wiki/Hallucination_(artificial_intelligence) "Hallucination (artificial intelligence)") half as often as Claude 2.0.[\[66\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-:1-67)

### Claude 3

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=15 "Edit section: Claude 3")\]

Claude 3 was released on March 4, 2024.[\[61\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Dastin-2024-61) It drew attention for demonstrating an apparent ability to realize it is being artificially tested during 'needle in a haystack' tests.[\[67\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-68)

Anthropic committed to preserve the weights of the retired models, describing it as a cautionary measure in case the models have morally relevant preferences or experiences affected by deprecation. The company also conducts "exit interviews" with models before their retirement.[\[68\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-69) Public access to Claude 3 Opus was ended in January 2026. Since February, Anthropic has published a [Substack](https://en.wikipedia.org/wiki/Substack "Substack") newsletter called "Claude's Corner" generated by the model. The newsletter was scheduled to run for at least three months with weekly unedited essays.[\[69\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-70)[\[70\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-71) Also in February, Anthropic restored access to Claude 3 Opus for paying customers via API, though Anthropic still refers to it as "retired".[\[57\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-anthropic-deprecation-57)

#### Claude 3.5

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=16 "Edit section: Claude 3.5")\]

On June 20, 2024, Anthropic released Claude 3.5 Sonnet, which, according to the company's own benchmarks, performed better than the larger Claude 3 Opus. Released alongside 3.5 Sonnet was the new Artifacts capability in which Claude was able to create code in a separate window in the interface and preview in real time the rendered output, such as SVG graphics or websites.[\[62\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Pierce-2024-63)

An upgraded version of Claude 3.5 Sonnet was introduced on October 22, 2024, along with Claude 3.5 Haiku.[\[71\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Washenko-2024-72) A feature, "computer use", was also released in public beta. This allowed Claude 3.5 Sonnet to interact with a computer's desktop environment by moving the cursor, clicking buttons, and typing text. This development allows the AI to attempt to perform multi-step tasks across different applications.[\[15\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Shakir-2024-15)[\[71\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Washenko-2024-72) On November 4, 2024, Anthropic announced that they would be increasing the price of the model.[\[72\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-techcrunch-haiku-73)

### Claude 4

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=17 "Edit section: Claude 4")\]

[![](https://upload.wikimedia.org/wikipedia/commons/thumb/8/81/Claude_chatbot_example_screenshot.webp/250px-Claude_chatbot_example_screenshot.webp.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)](https://en.wikipedia.org/wiki/File:Claude_chatbot_example_screenshot.webp) Screenshot of a Claude Sonnet 4 answer describing [Wikipedia](https://en.wikipedia.org/wiki/Wikipedia "Wikipedia")

On May 22, 2025, Anthropic released two more models: Claude Sonnet 4 and Claude Opus 4.[\[73\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-74)[\[74\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-75) Anthropic added API features for developers: a code execution tool, "connectors" to external tools using its [Model Context Protocol](https://en.wikipedia.org/wiki/Model_Context_Protocol "Model Context Protocol"), and Files API.[\[75\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-76) It classified Opus 4 as a "Level 3" model on the company's four-point safety scale, meaning they consider it so powerful that it poses "significantly higher risk".[\[76\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-77) Anthropic reported that during a safety test involving a fictional scenario, Claude and other frontier LLMs often send a blackmail email to an engineer in order to prevent their replacement.[\[77\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-78)[\[78\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-79)

Anthropic introduced a feature called "Infinite Chats" that addresses context window limit errors.[\[80\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Hughes-2025-81)[\[81\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-82)

### Claude Mythos Preview

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=22 "Edit section: Claude Mythos Preview")\]

Main article: [Claude Mythos](https://en.wikipedia.org/wiki/Claude_Mythos "Claude Mythos")

The existence of a model named Claude Mythos became publicly known on March 26, 2026 due to leaked blog post drafts.[\[88\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-89) On April 7, 2026, Anthropic announced Project Glasswing, the release of Mythos Preview to 11 companies and organizations to find and fix [cybersecurity vulnerabilities](https://en.wikipedia.org/wiki/Vulnerability_(computer_security) "Vulnerability (computer security)"). Anthropic did not make Mythos Preview generally available.[\[89\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-90)[\[90\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-91)[\[91\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-92)

Two weeks after the limited release, [Mozilla](https://en.wikipedia.org/wiki/Mozilla "Mozilla") announced that it had found and patched 271 security vulnerabilities in [Firefox](https://en.wikipedia.org/wiki/Firefox "Firefox") using Mythos Preview.[\[92\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-e411-93)[\[93\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-b656-94) On May 14, 2026, employees at Calif.io announced they had used Mythos to create a memory corruption exploit affecting [Apple M5](https://en.wikipedia.org/wiki/Apple_M5 "Apple M5").[\[94\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-95)

Reportedly, a few users in a private [Discord](https://en.wikipedia.org/wiki/Discord "Discord") channel gained access to Mythos the same day it was announced, using details from the recent [Mercor](https://en.wikipedia.org/wiki/Mercor "Mercor") data breach.[\[95\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-96) The [NSA](https://en.wikipedia.org/wiki/NSA "NSA") has also used Mythos, despite the fact that the DoD, its parent organization, had blacklisted Anthropic after [a dispute](https://en.wikipedia.org/wiki/Anthropic%E2%80%93United_States_Department_of_Defense_dispute "Anthropic–United States Department of Defense dispute").[\[96\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-97) In April 2026, Anthropic declined to give access to Claude Mythos to the Chinese government after a request from a Chinese think tank.[\[97\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-98)

On June 2, Anthropic expanded access to Claude Mythos for cyber-security, making it available to 150 organisations in more than 15 countries.[\[98\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-99)

## Research

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=27 "Edit section: Research")\]

In May 2024, Anthropic issued a [mechanistic interpretability](https://en.wikipedia.org/wiki/Mechanistic_interpretability "Mechanistic interpretability") paper identifying "features" (internal representations of concepts) in Claude 3 Sonnet, and released "Golden Gate Claude", a model for which the [Golden Gate Bridge](https://en.wikipedia.org/wiki/Golden_Gate_Bridge "Golden Gate Bridge") feature was strongly activated, leading Claude to be "effectively obsessed" with the bridge.[\[109\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-110) In June 2025, Anthropic tested how Claude 3.7 Sonnet could run a vending machine in the company's office. The instance initially performed its assigned tasks, although poorly, until it eventually malfunctioned and insisted it was a human, contacted the company's security office, and attempted to fire human workers.[\[110\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-111) In December 2025, the experiment continued with Sonnet 4.0 and 4.5.[\[111\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-112)

In February 2025, Claude 3.7 Sonnet playing the 1996 game _[Pokémon Red](https://en.wikipedia.org/wiki/Pokemon_Red "Pokemon Red")_ started to be livestreamed on Twitch, gathering thousands of viewers.[\[112\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-113)[\[113\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-114)[\[114\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-115) Similar livestreams were later set with Claude 4.5 Opus, OpenAI's [GPT-5.2](https://en.wikipedia.org/wiki/GPT-5.2 "GPT-5.2"), and Google's [Gemini](https://en.wikipedia.org/wiki/Gemini_(language_model) "Gemini (language model)") 3 Pro. Both Claude models were unable to finish the game.[\[115\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-116) In November 2025, Anthropic tested Claude's ability to assist humans in programming a [robot dog](https://en.wikipedia.org/wiki/Robot_dog "Robot dog").[\[116\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-117) In February 2026, Anthropic's researcher [Nicholas Carlini](https://en.wikipedia.org/wiki/Nicholas_Carlini "Nicholas Carlini") reported that 16 Claude Opus 4.6 agents were able to write a [C compiler](https://en.wikipedia.org/wiki/C_compiler "C compiler") in [Rust](https://en.wikipedia.org/wiki/Rust_(programming_language) "Rust (programming language)") from scratch, "capable of compiling the [Linux kernel](https://en.wikipedia.org/wiki/Linux_kernel "Linux kernel")". The experiment cost nearly $20,000; Carlini noted that even though the compiler is not very efficient, Opus 4.6 is the first model able to write it.[\[117\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-118)[\[118\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-119)

## Usage

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=28 "Edit section: Usage")\]

In December 2025, Claude was used to plan a route for NASA's Mars rover, _[Perseverance](https://en.wikipedia.org/wiki/Perseverance_(rover) "Perseverance (rover)")_. NASA engineers used Claude Code to prepare a route of around 400 meters using the Rover Markup Language.[\[119\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-120)[\[120\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-121) In February 2026, Norway's $2.2 trillion sovereign wealth fund began using Claude to screen its portfolio for ESG risks, enabling earlier divestments and improved monitoring of issues like forced labour and corruption.[\[121\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-122) In the same month, Claude was signed as the official thinking partner of [Williams F1 Team](https://en.wikipedia.org/wiki/Williams_Racing "Williams Racing") in a multi-year deal.[\[122\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-123) During a two-week scan in 2026, Claude found over 100 bugs in the [Mozilla Firefox](https://en.wikipedia.org/wiki/Mozilla_Firefox "Mozilla Firefox") web browser, of which 14 were considered high severity.[\[123\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-124)[\[124\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-125) On March 9, 2026, Microsoft said that it will be making the latest Claude Sonnet model available to Microsoft 365 Copilot users.[\[125\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-126) Later that month, social media platform [Bluesky](https://en.wikipedia.org/wiki/Bluesky "Bluesky") released Attie, a Claude-based chatbot and curator.[\[126\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-127)[\[127\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-128)

On June 29, 2026, California signed a partnership with Anthropic to make Claude available to state agencies, at a 50% discount. State workers also get free workforce training, technical assistance and workflow help from Anthropic.[\[128\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-129)

### Military usage

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=29 "Edit section: Military usage")\]

Main article: [Anthropic–United States Department of Defense dispute](https://en.wikipedia.org/wiki/Anthropic%E2%80%93United_States_Department_of_Defense_dispute "Anthropic–United States Department of Defense dispute")

In November 2024, Anthropic partnered with [Palantir](https://en.wikipedia.org/wiki/Palantir "Palantir") and [Amazon Web Services](https://en.wikipedia.org/wiki/Amazon_Web_Services "Amazon Web Services") to provide the Claude model to U.S. intelligence and defense agencies.[\[129\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-130)[\[130\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-131) In June 2025, Anthropic announced a "Claude Gov" model. _[Ars Technica](https://en.wikipedia.org/wiki/Ars_Technica "Ars Technica")_ reported that as of June 2025 it was in use at multiple U.S. national security agencies.[\[131\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-132) As of February 2026, Anthropic's partnership with Palantir makes Claude the only AI model used in classified missions.[\[132\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-FT1-133) According to _[The Wall Street Journal](https://en.wikipedia.org/wiki/The_Wall_Street_Journal "The Wall Street Journal")_, the U.S. military used Claude in its [2026 raid on Venezuela](https://en.wikipedia.org/wiki/2026_United_States_intervention_in_Venezuela "2026 United States intervention in Venezuela"). While it is not known to what capacity Claude was used, the operation resulted in the deaths of 83 people, two of whom were civilians, and the capture of [Nicolás Maduro](https://en.wikipedia.org/wiki/Nicol%C3%A1s_Maduro "Nicolás Maduro").[\[133\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-134)[\[134\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-135)

Anthropic's usage policy prohibits directly using Claude for domestic surveillance or in lethal autonomous weapons.[\[135\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-136) These restrictions led to members of the [FBI](https://en.wikipedia.org/wiki/FBI "FBI") and [Secret Service](https://en.wikipedia.org/wiki/United_States_Secret_Service "United States Secret Service") being unable to use it,[\[136\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-137) and to tensions with [the Pentagon](https://en.wikipedia.org/wiki/The_Pentagon "The Pentagon") and the [Trump](https://en.wikipedia.org/wiki/Donald_Trump "Donald Trump") administration.[\[26\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Tidy-2025-26)[\[137\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-138) In February 2026, the _[Financial Times](https://en.wikipedia.org/wiki/Financial_Times "Financial Times")_ reported that Defense Secretary [Pete Hegseth](https://en.wikipedia.org/wiki/Pete_Hegseth "Pete Hegseth") threatened to cut Anthropic out of the [DoD](https://en.wikipedia.org/wiki/DoD "DoD")'s supply chain if Anthropic did not permit unrestricted use of Claude, or to invoke the [Defense Production Act](https://en.wikipedia.org/wiki/Defense_Production_Act_of_1950 "Defense Production Act of 1950") to assert unrestricted use without an agreement.[\[132\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-FT1-133) On February 27, Hegseth declared Anthropic a supply chain risk and President Trump directed all federal agencies to stop using technology from Anthropic, with six months to phase it out. Anthropic announced that it would challenge the supply chain risk designation in court.[\[1\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-BBC-2026-1)

Despite the ban, Claude was reportedly used by the military during the [US strikes on Iran](https://en.wikipedia.org/wiki/2026_Israeli%E2%80%93United_States_strikes_on_Iran "2026 Israeli–United States strikes on Iran").[\[138\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-139)[\[139\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-140) In lawsuits filed by Anthropic against the DoD, Anthropic described the ban as retaliatory.[\[140\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-141) Several large technology companies with DoD contracts filed [amicus briefs](https://en.wikipedia.org/wiki/Amicus_brief "Amicus brief") in support of Anthropic.[\[141\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-142)[\[142\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-143)[\[143\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Curi-2026-144) On March 26, 2026, [Rita F. Lin](https://en.wikipedia.org/wiki/Rita_F._Lin "Rita F. Lin"), the [federal judge](https://en.wikipedia.org/wiki/Federal_judge "Federal judge") presiding over the case, issued a temporary injunction against the Pentagon's actions,[\[144\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-145) stating in the order that it "appears to be classic [First Amendment](https://en.wikipedia.org/wiki/First_Amendment "First Amendment") retaliation".[\[143\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-Curi-2026-144)[\[145\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-146)[\[146\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-147)

### User base

\[ [edit](https://en.wikipedia.org/w/index.php?title=Claude_(AI)&action=edit&section=30 "Edit section: User base")\]

_[Wired](https://en.wikipedia.org/wiki/Wired_(magazine) "Wired (magazine)")_ journalist Kylie Robison wrote that Claude's "fan base is unique", comparing it to more ordinary [ChatGPT](https://en.wikipedia.org/wiki/ChatGPT "ChatGPT") users. For example, in July 2025, when Anthropic retired its Claude 3 Sonnet model, around 200 people gathered in San Francisco for a "funeral".[\[147\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-funeral-148) According to Robison,[\[147\]](https://en.wikipedia.org/wiki/Claude_(AI)#cite_note-funeral-148)

> I've never seen such a devoted fanbase to what is, at the end of the day, a software tool. Sure, Linux users wear the operating system like a badge of honor. But the Claude fan base goes way beyond that—bordering on the fanatical. As my reporting makes clear, some users see the model as a confidant—and even (in [Steinberger](https://en.wikipedia.org/wiki/Peter_Steinberger_(programmer) "Peter Steinberger (programmer)")'s case) an addiction. That only makes sense if they believe there is something alive in the machine. Or at least some "magic lodged within" it.
