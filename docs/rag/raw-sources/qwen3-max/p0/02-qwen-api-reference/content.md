Model Studio offers multiple interfaces for text generation models:

- [OpenAI-compatible Chat Completion](https://www.alibabacloud.com/help/en/model-studio/qwen-api-via-openai-chat-completions ""): Drop-in compatibility with OpenAI client libraries. The lowest-friction path for migrating existing apps or connecting third-party tools.

- [OpenAI-compatible Responses](https://www.alibabacloud.com/help/en/model-studio/openai-compatible-responses/ ""): Ships with built-in web search, code interpreter, and web extractor. Conversation history is managed automatically.

- [Anthropic-compatible Messages](https://www.alibabacloud.com/help/en/model-studio/anthropic-api-messages ""): Compatible with the Anthropic Messages API. Supports thinking and tool calling.

- [DashScope](https://www.alibabacloud.com/help/en/model-studio/qwen-api-via-dashscope ""): Model Studio's native interface. Provides the most complete set of features and parameters.
