FAQ
How do I use Kimi K3 in Kimi Code?
Kimi K3 can be used in Kimi Code from the terminal or supported IDEs. In Kimi Code CLI, use the /model command to select Kimi K3. In Kimi Code for VS Code and Cursor, select Kimi K3 from the model dropdown in the input bar.
How do I use Widgets and Dashboard in Kimi Work?
In Kimi Work, you can create interactive Widgets directly in a conversation and connect them to local data or external plugins for ongoing updates. You can then add the Widgets you want to keep to Dashboard, where they remain available in a persistent view organized around a topic, project, or goal. This makes it easier to keep frequently used information and tools in one place and return to them across different tasks.
What is Kimi K3?
Kimi K3 is an open-weight, native multimodal model developed by Moonshot AI. It has 2.8 trillion total parameters and is built on Kimi Delta Attention (KDA) and Attention Residuals (AttnRes), with native vision capabilities and a context window of up to 1 million tokens. It is designed for long-horizon coding, knowledge work, and reasoning.
Is Kimi K3 open source?
Yes. Kimi K3 is open source. Its full model weights are available on Hugging Face, and both the model weights and code are released under the Kimi K3 License. The license allows users to run, deploy, fine-tune, and modify the model, subject to its terms and conditions.
How can I access Kimi K3?
Kimi K3 is available through Kimi Web, the Kimi mobile app, Kimi Work, Kimi Code, and the Kimi API. The Kimi app is available on iOS, Android, and HarmonyOS. Organizations can use Kimi through Kimi Business, and developers can also download the model weights from Hugging Face for their own deployments.
What is Kimi K3's context window?
Kimi K3 supports a context window of up to 1 million tokens, allowing it to keep more information in context over long conversations and complex tasks.
Is Kimi K3 multimodal?
Yes. Kimi K3 is a native multimodal model that can understand text, images, and video within the same model. This allows it to work with visual information such as screenshots, documents, and video alongside text.
