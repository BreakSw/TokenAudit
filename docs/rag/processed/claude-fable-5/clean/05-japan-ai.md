Claude Fable 5とは
Claude Fable 5は、Anthropicが2026年6月9日にリリースしたMythosクラスの能力を一般ユーザー向けに安全機構付きで公開した最上位AIモデルです。
Anthropicはこれまで、高性能すぎて悪用リスクが大きいモデル群を「Mythosクラス」と位置づけ、一般公開を控えてきました。2026年4月に発表されたProject Glasswingでは、Mythos Previewがサイバー防衛や重要ソフトウェアの保護に関わる限られた組織に提供されていた経緯があります。Claude Fable 5は、このMythosクラスの能力を維持しながら、独立した分類器AIによる安全機構を組み込むことで、一般の有料プランやAPI経由で広く利用できるようにしたモデルです。
テキストと画像の両方を入力として受け付け、100万トークンのコンテキストウィンドウと最大12.8万トークンの出力に対応しています。長時間にわたる複雑なタスクでも文脈を維持しながら自律的に作業を進められる点が、従来のOpus 4.8との大きな違いです。

「Mythosクラス」とは何か
Mythosクラスとは、Anthropicが定義する最上位の能力階層に位置するAIモデル群の総称です。
ClaudeのモデルはHaikuに加え、Sonnet（軽量・高速）、Opus（高性能・汎用）という構成で提供されていました。Mythosクラスはこの上に新設された階層であり、ソフトウェアエンジニアリングや科学研究、長時間の自律タスクにおいて、Opusを大幅に上回る能力を備えています。
Anthropicが2026年4月に発表したProject Glasswingでは、Mythos Previewが米国政府との連携のもとサイバー防衛組織に限定提供されていました。高度なサイバーセキュリティ能力や生物・化学分野での知識が悪用されるリスクを考慮し、一般公開を見送っていた経緯があります。Claude Fable 5は、この能力を維持しつつ安全機構を組み込むことで、Mythosクラスとして初めて一般提供が実現したモデルです。

Fable 5とMythos 5の違い
Claude Fable 5とClaude Mythos 5は同一の基盤モデルであり、違いはセーフガードの有無のみです。
両モデルは同じ重み（パラメータ）を共有しており、基本的な能力に差はありません。Fable 5には独立した分類器AIによる安全機構が組み込まれ、サイバーセキュリティや生物・化学、モデル蒸留（ディスティレーション）の3領域で高リスクと判定されたリクエストに対して、Opus 4.8が代わりに応答するフォールバック方式が採用されています。
一方のMythos 5は、このサイバーセキュリティ領域の制限が解除されており、サイバー防衛の専門家が攻撃手法の分析や脆弱性の検証に活用できる設計です。

Fableの名前の由来
Fable（読み方：フェイブル）は英語で「寓話」、Mythos（ミュトス）は「神話」を意味します。寓話は教訓を含みながらも広く親しまれる物語であり、神話はより根源的で強大な力を象徴します。
Fable 5が「安全に語られる物語」として一般に公開され、Mythos 5が「制御された神話的な力」として限定提供されるという構図は、両モデルの提供方針を端的に表しています。

ベンチマークの数字を見るときの注意点
ベンチマーク結果を評価する際には、数値だけで「最強モデル」と判断しないことが重要です。
ベンチマークごとに評価条件やタスクの性質が異なるため、特定のベンチマークで高スコアを記録したモデルが、すべての実務タスクで最適とは限りません。OSWorld-Verifiedのようなコンピューター操作系ベンチマークでは、Fable 5の85.0%に対してMythos Previewが85.4%とわずかに上回る場面もあります。
また、ベンチマークの多くはAnthropicが自社で実施・公表したものであり、第三者による独立した検証が進行中の段階です。実務での体感性能はプロンプトの書き方やタスクの種類によって大きく変動するため、自社のユースケースで実際に試してから判断することが、最も確実な評価方法です。

安全機構とフォールバックの仕組み
Claude Fable 5の最大の特徴は、高リスクなリクエストを検知した際にOpus 4.8が代わりに応答するフォールバック方式を採用している点です。
従来のAIモデルでは、危険と判断されたリクエストに対して単純に「回答を拒否する」方式が一般的でした。Fable 5では、独立した分類器AIがリクエストの内容をリアルタイムで分析し、高リスクと判定された場合にのみ、高リスクと判定された場合は拒否またはOpus 4.8へのフォールバックが発生します。ユーザーには応答がOpus 4.8に切り替わった旨が通知されるため、透明性が確保されている点が大きな特徴です。
Anthropicの初期データによれば、通常のセッションにおけるフォールバックの発生率は5%未満にとどまり、95%以上のやり取りではFable 5がそのまま応答しています。
3つの領域で応答が切り替わる
フォールバックが発動する領域は、サイバーセキュリティ、生物・化学、モデル蒸留の3つに限定されています。
サイバーセキュリティ: 攻撃手法の具体的な実装方法や、脆弱性を悪用するコードの生成など、サイバー攻撃に直接利用できる情報のリクエスト
生物・化学: 生物兵器や化学兵器の製造に関わる知識、危険な化合物の合成手順など、大量破壊兵器に関連するリクエスト
モデル蒸留（ディスティレーション）: Fable 5の能力を別のモデルに転写・複製しようとする試み
これらの領域に該当しない一般的な業務利用、すなわちコーディング支援や文書作成、データ分析、画像認識といったタスクでは、フォールバックが発動することはほぼありません。分類器の精度はレッドチーム評価で「最も堅牢」との外部評価を受けています。

実務への影響
フォールバックが発動した場合でも、ユーザーは応答を受け取ることができます。
Webやデスクトップ、モバイルアプリでは、自動的にOpus 4.8へフォールバックし、切り替わった旨の通知が表示されます。APIでは、分類器が拒否した場合にレスポンスのstop_reasonが"refusal"となり、stop_details.categoryでどの分類器が作動したかを確認できます。自動的にOpus 4.8へリトライさせるには、fallbacksパラメータ（ベータ版、Claude APIとClaude Platform on AWSのみ対応）を設定するか、クライアント側でリトライ処理を実装する必要があります。
セキュリティ関連の業務を主に扱う組織にとっては、Fable 5のサイバーセキュリティ領域がOpus 4.8相当の応答に制限される点を事前に把握しておくことが重要です。ただし、Opus 4.8自体が高性能なモデルであるため、フォールバック先の応答品質が著しく低下するわけではありません。
データ保持ポリシー
Mythosクラスのモデルでは、すべてのトラフィックについて30日間のデータ保持が必須です。
この30日間のデータ保持は、Fable 5とMythos 5の両方に適用されます。保持されたデータは、新しいジェイルブレイク（安全機構の回避手法）の検知や、分類器の誤検知の特定・改善といったセキュリティ目的にのみ使用されます。Anthropicは公式に「保持データを新しいClaudeモデルの学習に使用しない」と明言しており、セキュリティに関係しない目的での利用も行わないとしています。
従来のClaudeモデルでは、Enterprise向けにZDR（ゼロデータリテンション）オプションが提供されていましたが、Fable 5ではZDRに対応していません。機密性の高いデータを扱う業務では、Opus 4.8などZDR対応モデルの利用を検討する必要があります。

「重いエージェントタスク専用機」としてFable 5を位置づけ、日常業務にはSonnetやOpusを使うという運用が、現時点では最も現実的な活用方針です。
Claude Fable 5導入前に確認すべきポイント
Claude Fable 5を業務に導入する前に、料金・安全機構・データ保持の3つの観点から自社の要件との適合性を事前に確認することが不可欠です。
以下のチェックリストを参考に、導入判断を行ってください。
フォールバック領域の業務影響
自社の業務がフォールバック対象の3領域に該当するかどうかを、事前に確認してください。
サイバーセキュリティ、生物・化学、モデル蒸留の3領域に関連する業務を主に扱う場合、Fable 5ではなくOpus 4.8相当の応答が返される場面が増えます。セキュリティ企業やバイオテクノロジー企業など、これらの領域が業務の中核を占める組織では、Fable 5の導入効果が限定的になる可能性があります。
一方で、一般的なソフトウェア開発や文書作成、データ分析が主な業務であれば、フォールバックの影響はほぼありません。Anthropicの初期データでは、通常セッションの95%以上でFable 5がそのまま応答しており、大多数のユースケースでは安全機構の存在を意識する必要はないといえます。
30日間のデータ保持ポリシー
Fable 5ではZDRに対応していないため、機密データの取り扱いについてコンプライアンス部門との事前確認が必要です。
30日間のデータ保持はMythosクラスのモデルすべてに適用される方針であり、オプトアウトはできません。保持データはセキュリティ目的にのみ使用され、モデル学習には利用されないとAnthropicは明言していますが、業界規制や社内ポリシーによってはこの保持期間自体が許容されない場合があります。
機密性の高い顧客データや個人情報を扱うタスクでは、Opus 4.8などZDR対応モデルを使用し、Fable 5は機密性の低いタスクに限定するという運用ルールの策定が推奨されます。

Claude Fable 5に関してよくある質問
Claude Fable 5は無料で使えますか？
無料プランではClaude Fable 5を利用できません。Pro（月額20ドル）以上の有料プラン、またはAPI（入力100万トークンあたり10ドル、出力100万トークンあたり50ドル）での利用が必要です。2026年7月13日までは、有料プラン内で追加課金なしでFable 5を利用できます。
Fable 5とMythos 5は何が違いますか？
Fable 5とMythos 5は同一の基盤モデルであり、違いはセーフガードの有無のみです。Fable 5にはサイバーセキュリティ、生物・化学、モデル蒸留の3領域でフォールバック機構が組み込まれていますが、Mythos 5ではサイバーセキュリティ領域の制限が解除されています。Mythos 5はProject Glasswingを通じた限定提供であり、一般ユーザーが利用できるのはFable 5のみです。
Opus 4.8からすぐ乗り換えるべきですか？
全面的な乗り換えは推奨されません。Fable 5はOpus 4.8の2倍の料金であり、ZDRにも対応していないため、すべてのタスクをFable 5に置き換えるとコストが増大し、データ保持の制約も生じます。複雑なエージェントタスクや大規模なコード移行にはFable 5を、日常的なタスクやコスト重視の作業にはOpus 4.8やSonnet 4.6を使うという使い分けが最適です。
Claude Fable 5の性能・料金・安全設計を理解して最適な活用を
Claude Fable 5は、Anthropicが一般提供するモデルとして初めてMythosクラスの能力を備えた、2026年7月時点の最上位AIモデルです。SWE-bench Proで80.3%を記録するコーディング性能、100万トークンのコンテキストと12.8万トークンの出力、そしてフォールバック方式による安全設計は、従来モデルとは一線を画す進化といえます。
一方で、Opus 4.8の2倍となるAPI料金、30日間のデータ保持義務、ZDR非対応という制約も存在します。これらの特性を正しく理解したうえで、タスクの難易度とコストのバランスに応じてモデルを使い分けることが、Claude Fable 5を最大限に活用するための鍵です。
